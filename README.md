# Fjordfeast

Clone leve estilo *Fat Princess* com tema viking. Dois clas — **Lobo** e **Dragao** — roubam e **engordam** suas feras miticas com carne pra dificultar o roubo. Arena 3D, classes assimetricas, co-op de sofa + online.

## Como jogar (teste)
1. Baixe o `.zip` mais recente em **[Releases](../../releases)**.
2. Extraia a pasta.
3. Rode **`Jogar.bat`** — o Godot ja vem embutido, nao precisa instalar nada.

### Online entre casas diferentes
O host precisa **abrir a porta** no roteador (ou usar VPN tipo Radmin/Hamachi). Na mesma rede (LAN), conecta direto pelo IP local.
